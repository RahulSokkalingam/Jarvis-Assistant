# Jarvis Autonomous Voice Assistant & Cyber HUD for Antigravity IDE

A native, high-tech AI systems extension for **Antigravity IDE** powered by **openWakeWord**, **Groq Whisper**, **Llama 3.3**, and **n8n Automation Engine**.

---

## ⚡ Features

- 🎙️ **Zero-Latency Voice Assistant**: Activate anytime with *"Hey Jarvis"* (`Ctrl+Alt+J`).
- 🌐 **Embedded Cyber HUD**: Holographic Activity Bar sidebar with animated arc-reactor, live voice transcripts, and telemetry feed.
- 🖥️ **Desktop Holographic Window**: Launch high-FPS PyQt6 cybernetic window on demand (`Ctrl+Alt+H`).
- 🔄 **Autonomous n8n Workflow Server**: Auto-starts background workflow automation engine on `http://localhost:5678`.
- 🔑 **Secure Groq API Setup**: Prompts for your Groq API key on install and securely syncs to your project `.env`.
- 🚀 **Multi-Project Targeting**: Automatically initializes Git and controls branch workflows for whichever workspace is open in Antigravity IDE.
